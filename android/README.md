# Ace 网球课表 · 安卓原生版

使用 Android 原生界面与 AlarmManager 构建的离线排课应用，不包含 WebView，也不需要网络权限。

主要功能：课程增改删、每周重复排课、冲突检查、学员统计、课时确认、课前提醒、响铃与振动、稍后提醒、设备重启后重排提醒、JSON 备份恢复。

最低系统 Android 8.0。默认课前 2 小时提醒。Android 12+ 需用户允许“闹钟和提醒”；Android 13+ 需用户允许通知。需要在设置页进行一次“10秒后测试提醒”，并确认锁屏时能收到提醒。勿扰、闹钟音量、厂商自启动和后台策略会影响实际提醒。强行停止后须重新打开应用。

构建：JDK 17、Gradle 8.11.1、Android SDK 35，执行 gradle :app:assembleRelease。发布前需使用长期保管的私钥签名。不要将签名密钥提交到仓库。

CI 会在 Android 15 模拟器验证原生页面、数据、冲突检查、实际后台定时提醒、通知以及设备重启后重排提醒。
